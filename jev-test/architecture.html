Orchestration pattern

Jev as a fast decision layer

Every incoming task hits Jev first. It answers a typed question — routine or complex? — in under 500ms. Routine work executes immediately; only tasks that need real reasoning pay the cost of a full LLM call.

● Fast path

Routine decisions

Jev classifies and scores directly — the orchestrator acts on the typed result with no further model call.

  • Examples: intent routing, tool selection, cached-answer lookup, simple validation
  • Cost: $0.042 / M input tokens, output free
70–500ms
● Complex path

Escalated reasoning

Jev flags the task as needing generation or multi-step reasoning, so the orchestrator hands it to a full LLM.

  • Examples: writing code, drafting text, open-ended planning, ambiguous requests
  • Cost: full model pricing — this is where it belongs
seconds to tens of seconds
What Jev doesn't do: it never generates the action or the content itself — only the routing decision. The browser-opening, code-writing, or reply-drafting still happens in the fast path's direct-execute step or in the complex path's model call. Jev's job is to keep the expensive call from firing on every single decision the agent makes.
